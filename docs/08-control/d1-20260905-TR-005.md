## Orden de trabajo

1. **Options + config** — Clase opciones camelCase/Pascal alineada a plantilla lab (`AgentId`, `ClientId`, `AgentToken`, `GatewayUrl`, bloque `Sql` opcional). Cargar `appsettings.json` + `appsettings.Development.json` + `appsettings.local.json` (opcional file). Validar al start: sin token/url → no conectar / no fingir online. **Prohibido** default `dev-agent-token`.
2. **Serilog** — Sink archivo bajo carpeta local (ej. `logs/paqagent-.log`); enrichers; filtros: nunca escribir `AgentToken` ni password SQL.
3. **Host** — `UseWindowsService()`; `AddHostedService` del conector; lab sigue con `dotnet run`.
4. **SignalR client** — Construir URL `GatewayUrl` + query M8 (si `GatewayUrl` ya trae `/agent-hub`, no duplicar). `HubConnection` + `WithAutomaticReconnect` **y/o** Polly con delays **5,10,20,30,60** s (P3). `OnConnected` / closed → logs readiness.
5. **Heartbeat loop** — Cada `AgentDefaults.HeartbeatSeconds`; payload `AgentHeartbeat` (agentId, clientId, AgentVersion=assembly, Readiness, TimestampUtc). Tras auth OK: readiness al menos `gateway_authenticated`; si hay SQL config y se prueba conexión (opcional tramo 3): avanzar `sql_connection_ok` sin ejecutar SQL libre.
6. **Job handlers (P6)** — `On<JobRequest>(ExecuteJob)`: responder `CompleteJob` con stub seguro (ej. `success` + data mock **o** `degraded` si no hay SQL) — **sin** abrir la puerta a SQL arbitrario. Round-trip real `diagnostics.run` = TR-006.
7. **Identidad** — Log/heartbeat: `Environment.MachineName`; `sql.server` de config si existe; version assembly.
8. **lab-local.md** — Comandos tramo 2: Gateway + PaqAgent + curl status; plantilla JSON; nota hostname ops `gateway.paqsystems.com`.
9. **Pruebas** — ver sección siguiente.
10. **Traza TR-005** — archivos, comandos, pendientes; Estado → `Pendiente de Revisión`.
