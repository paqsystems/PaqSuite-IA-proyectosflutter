## Orden de trabajo

1. **PaqContracts** — Constantes hub `ExecuteJob`/`CompleteJob`; `ErrorCodes` (`AGENT_OFFLINE`, `AGENT_TIMEOUT`, auth); DTO status si no existe; asegurar `JobRequest`/`JobResult`/`AgentHeartbeat`/`AgentDefaults` alineados a M6–M9.
2. **Options + DI** — `GatewayOptions`, `LaravelApiOptions`; JSON camelCase global; HttpClient tipado para authenticate.
3. **AgentRegistry** — ConcurrentDictionary `agentId` → connectionId, lastSeenAt, lastSeenIp, readiness opcional; `IsOnline(ttl)`; remove on disconnect.
4. **IAgentAuthenticator** — Impl Laravel HTTP (M4) + cache MemoryCache 60s (M3); stub Dev (M5) detrás de `IHostEnvironment.IsDevelopment()` + config explícita (ej. `Gateway:UseDevAuthStub=true`), **nunca** activo si `Production`.
5. **AgentHub** — Path `/agent-hub`; `OnConnectedAsync` lee query M8 → auth → register; hub method heartbeat; `CompleteJob` completa `TaskCompletionSource` del job en vuelo; `OnDisconnectedAsync` limpia registro.
6. **Internal API** — Middleware/filter `X-Paq-Internal-Api-Key`; `GET .../status`; `POST .../jobs/send` síncrono: genera `jobId`, si offline → result offline; else `Clients.Client(connectionId).ExecuteJob(...)` + wait TCS hasta timeout → timeout/result; logs sin secretos.
7. **Shutdown** — `IHostApplicationLifetime` / disposing: completar TCS pendientes como `cancelled`.
8. **Config** — `appsettings.json` sin secretos productivos; `appsettings.Development.json` con keys de lab obvias (no `dev-agent-token` como token de agente); documentar en Traza.
9. **Tests** — ver sección siguiente.
10. **Traza TR-002** — archivos, comandos `dotnet test`, pendientes (auth Laravel real).

## Riesgos

| Riesgo | Mitigación |
|--------|------------|
| SignalR client invoke desde server + CompleteJob race | Un `ConcurrentDictionary<jobId, TCS>`; Completar solo una vez |
| Query string expone token en logs de proxy | No loguear query; en prod WSS; aceptado MVP (M8) |
| Stub Dev filtrado a Production por error | Guard doble: env + flag; test que Production rechaza stub |
| TTL flaky en tests | Inyectar `TimeProvider` o TTL corto override en test |
| WebApplicationFactory + SignalR cliente | Usar `HubConnectionBuilder` contra `Server.CreateHandler()` / URL test |
