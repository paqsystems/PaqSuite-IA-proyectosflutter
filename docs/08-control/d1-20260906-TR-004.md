## Orden de trabajo

### A — Modelo y SQL port (PaqAgent)

1. `SqlOptions.Port` (`int?`); `SqlConnectionStringFactory`: si Port tiene valor, `DataSource = $"{server},{port}"` (no tocar named instances con `\`).
2. Actualizar `appsettings.local.json.example`.
3. Tests existentes PaqAgent siguen verdes (ajustar si factory tests).

### B — Núcleo instalador (sin servicio aún)

1. Estructura: `WizardForm` + paneles/pasos 0–4; estado compartido `InstallerSession` (credenciales, flags pruebas, paths).
2. `RuntimeDetector` (.NET Desktop 8 x64 — registro / runtime list documentado en código).
3. `CredentialValidator` (vacíos; sin defaults de token).
4. `SqlConnectionTester` (reuse lógica factory; ref proyecto o duplicar builder mínimo en installer para no cargar Worker).
5. `GatewayReachabilityTester` (HttpClient a URL hub / negotiate; timeout corto; mensaje DNS/TLS/443).
6. Unit tests de detector/validator/testers (mock donde haga falta).

### C — UI pasos 0–2

1. Paso 0: textos D19; botón “Descargar/Instalar runtime” (URL Microsoft fija + intento winget opcional); Continuar con ACK.
2. Paso 1: bindings campos; default Gateway Q1; grupo avanzado TLS + port.
3. Paso 2: botones Probar SQL / Probar Gateway; checkbox override; no avanzar a Instalar sin SQL OK; Gateway OK o override.

### D — Instalar servicio + settings (pasos 3–4)

1. `AppSettingsLocalWriter` → JSON camelCase = AgentOptions.
2. `AgentFilesCopier` desde `agent/` relativo al exe del instalador (layout release).
3. `WindowsServiceInstaller` (`sc create`/`sc config`/`sc start` o `ServiceController` + create) nombre **`PaqAgent`**, binPath = exe SC del agente; start=auto; requiere elevación (manifest `requireAdministrator`).
4. Overwrite confirm de local.json.
5. Paso 4: estado servicio + mensaje “esperando online”.

### E — Empaquetado

1. csproj instalador: `PublishSingleFile`, `SelfContained`, `RuntimeIdentifier=win-x64`, Windows Forms.
2. Script o doc en Traza: `dotnet publish` PaqAgent SC → `dist/agent/`; publish Installer → `dist/`; zip + `Get-FileHash` SHA256.
3. Notas release: prerrequisito Desktop (refuerzo).

## Riesgos

| Riesgo | Mitigación |
|--------|------------|
| Crear servicio sin admin | Manifest requireAdministrator; mensaje claro si falla ACL |
| Named instance + port | UI: si server contiene `\`, deshabilitar/ignorar port (documentar) |
| Prueba Gateway frágil | Timeout corto; aceptar 401/404 negotiate como “alcanzable”; solo fallar en red/TLS/DNS |
| Zip sin carpeta `agent/` | Validar en paso 3; error accionable “paquete incompleto” |
| SC muy pesado | Aceptable MVP (Q2/Q5); no redist embebido adicional |
| Tests UI WinForms | Preferir tests de servicios puros; UI smoke manual en Traza |
