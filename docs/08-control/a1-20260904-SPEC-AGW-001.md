```md
### 6.4 Defaults de contrato Gateway (MVP)

- Authenticate Laravel: POST body JSON camelCase
  `{ "agentId": "...", "clientId": "...", "agentToken": "..." }`
  → 200 autorizado; 401 token/ids inválidos; 403 tenant inactivo.
- Cache de validación en Gateway: 60 s (configurable por env).
- GET /internal/agents/{agentId}/status →
  `{ "agentId", "status": "online"|"degraded"|"offline", "lastSeenAt", "lastSeenIp"? }`.
- POST /internal/jobs/send: espera el resultado del job o timeoutSeconds (síncrono MVP);
  header API key: `X-Paq-Internal-Api-Key` (único nombre en runbook).
```
